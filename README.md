# Fomento de la lectura en los jovenes de preparatoria

## ¿Porque elegi este proyecto?
Elegi este proyecto porque la lectura es algo enriquecedor en todos los ambitos para una persona, la lectura en la juventud ayuda a estimular la imaginación, la creatividad y el pensamiento crítico. Muchos jovenes no leen por el tiempo que pasan en el telefono o porque no han encontrado un libro para iniciar a hacerlo, o incluso, no encuentran su genero literario. Mi propuesta para el proyecto es hacer una pagina donde la gente pueda acceder a leer reseñas de libros o incluso pueda comprarlos o leerlos en PDF.
